# 云循 V3 M0 可点击原型

本目录只用于计划书 M0“需求冻结与原型”。它不是 M1 小程序工程，也不连接真实天气、定位、账户或健康数据。

原型场景：

- 腊八节与蒜不耐受排除；
- 轻微着凉与非医疗化推荐文案；
- 鸡蛋、西红柿、豆腐的食材匹配；
- 今日 / 食材 / 我的三栏导航；
- 食谱详情、收藏演示与安全说明。

直接打开 `dist/index.html` 可查看，或使用静态 HTTP 服务预览。

进入 M1 前必须完成：

1. `docs/M0_REQUIREMENTS_FREEZE.md` 的 10 项确认；
2. 三组内容的专业审核；
3. `docs/M0_USABILITY_TEST.md` 的 5 人测试并达标。

食谱主图由内置图像生成工具生成。最终提示词记录在 `../docs/IMAGE_ASSET_PROMPTS.md`；图片仅用于原型展示。
