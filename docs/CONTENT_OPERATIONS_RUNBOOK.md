# YunSync V2 内容更新与运营流程

本流程覆盖食材、食药物质、禁忌、安全规则、食谱及来源。种子和演示内容保持草稿；只有真实审核人完成范围确认、来源复核和明确确认后才能发布。

## 1. 生命周期

1. **提出**：记录目的、适用人群、变更原因和来源；
2. **编辑**：填写结构化字段、版本、来源日期和风险边界，禁止诊断、疗效保证、调药和目录外材料；
3. **自动校验**：运行批量校验、禁语守卫、引用完整性和测试；
4. **专业审核**：临床营养、中医药/法规负责人按职责签署，提交人与审核人分离；
5. **QA 验证**：验证发布目录、匹配、份量、替代、采购清单、安全分流和回滚；
6. **发布**：发布明确版本，记录审核人、时间和证据编号；
7. **监测**：跟踪反馈、不适、错误匹配和来源变更；
8. **停用/回滚**：发现风险时立即停用，恢复上一批准版本并保留审计。

## 2. 变更级别

| 级别 | 示例 | 最低门禁 |
|---|---|---|
| 紧急 | 安全规则错误、禁忌遗漏、法规变化 | 立即停用；专业负责人和事故负责人联合处置 |
| 重大 | 适用人群、核心配方、风险边界变化 | 双专业复核、QA 回归、版本发布 |
| 一般 | 做法、替代、展示文字修订 | 专业复核、自动校验、抽样 QA |
| 来源维护 | 链接、发布日期、来源版本更新 | 来源有效性复核并关联受影响内容 |

每周处理待审核、反馈和停用项；每月抽查发布目录与来源；每季度复核安全规则、食药物质目录和角色权限；法规或严重事故触发即时复核。

发布证据包括变更说明、内容和来源版本、审核角色、QA 用例、发布时间、停用/回滚关系和记录编号。记录中不得复制用户健康正文。
