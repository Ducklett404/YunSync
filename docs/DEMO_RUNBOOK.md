# YunSync 五分钟演示与降级运行手册

> 主演示数据：合成账号、合成体检报告、合成 14 天记录

## 1. 演示前门禁

1. 确认演示材料不包含真实姓名、联系方式、证件号码、病历或云密钥；
2. 运行 `scripts/verify.ps1`、敏感信息扫描、三轮合成主流程和材料检查；
3. 确认本地 Mock 版可独立运行，截图顺序与讲稿一致；
4. 只有 M9B/M10B 证据齐全时才把真实云版设为主路径；
5. 打开计时器，关闭无关通知，准备本手册和 [EVIDENCE_INDEX.md](EVIDENCE_INDEX.md)。

## 2. 五分钟讲稿

叙事要素固定为：问题、方案、创新、技术、效果、安全。效果部分只说明当前工程与合成测试结果，不声称真实健康效果。

| 时间 | 页面/材料 | 讲述重点 | 必须出现的证据 |
|---:|---|---|---|
| 0:00–0:35 | 标题与流程 | 通用建议难以回答“对我是否可执行、是否出现短期变化”；云循验证一个行动，不替代医生 | 合成数据与非诊疗声明 |
| 0:35–1:15 | 开始、报告确认 | 先授权和安全初筛；OCR 只是提取，字段必须逐项确认 | 风险拦截、原文/数值/单位/范围 |
| 1:15–1:55 | 候选行动 | 模板受治理、排序透明，AI 只能解释不能自由开方 | 三项分数、适用条件、停止条件、解释来源 |
| 1:55–2:40 | 个人实验 | 14 天 7:7 平衡日程锁定，一次只改变一个行动 | 随机日程、动态记录、缺失与不适 |
| 2:40–3:30 | 结果评估 | 展示描述统计、不确定区间和数据局限，不夸大短期差异 | 有效天数、完成率、区间、非诊疗声明 |
| 3:30–4:20 | 技术架构 | 前后端分层，云服务可替换；失败时缓存和 AI 可安全降级 | 架构图、请求 ID、迁移与安全门禁 |
| 4:20–5:00 | 创新与结论 | 从“生成建议”转向“可复现的个人行动验证”，保留审计和下一轮选择 | 测试证据、真实云/人员验收待办 |

讲述不得声称合成结果证明健康效果，不得把 Mock 调用描述为真实华为云调用。

## 3. 三套演示路径

### A. 真实云端版（条件未满足）

仅当真实 RDS/DCS/OBS/OCR/MaaS、HTTPS、日志告警、镜像扫描和公网性能证据齐全时启用。演示前必须完成健康检查、账号登录、报告对象读取、模型调用和告警通道抽查。当前状态：待 M9B/M10B。

### B. Mock 降级版（当前可用主备路径）

使用仓库代码、本地 SQLite、私有目录、合成种子和明确标注的 Mock OCR/MaaS。它覆盖完整产品闭环，可在无云凭据时演示，但讲述中必须主动说明它不是真实云调用。

```powershell
Copy-Item .env.local.example .env
.\start.ps1
```

若 `.env` 已正确配置，不要覆盖。打开 `http://localhost:5173` 后按五分钟讲稿执行。

### C. 截图/离线版（素材脚本已准备）

按以下顺序准备无个人信息的截图或录屏帧：知情与初筛、报告逐项确认、行动排序、14 天日程、每日记录、结果区间、技术架构、测试与边界。每张图标注“合成数据演示”，并把对应讲述控制在主讲稿相同时间段。

当前只完成素材顺序与口径，正式截图包和离线视频仍待录制，因此不能将此路径标记为已验收。

## 4. 30 秒切换协议

| 用时目标 | 操作 |
|---:|---|
| 0–5 秒 | 说明“当前云端/网络不可用，切换到同版本的合成数据备份路径” |
| 5–15 秒 | 切换到预先打开的本地 Mock 标签；若本地也不可用，打开截图/离线视频 |
| 15–25 秒 | 在当前步骤对应页面或画面继续讲述，不重走已完成步骤 |
| 25–30 秒 | 再次说明数据来源和降级范围，继续主时间线 |

这是目标流程，不是已完成的真人计时证据。正式提交前至少进行 3 轮演练，记录每轮切换用时、卡点和改进。

## 5. 中断处理口径

- OCR/MaaS 超时：说明系统进入明确失败或固定安全解释，不伪造云调用；
- 页面请求失败：保留当前叙事位置并切换备份，不反复刷新；
- 结果被追问：只陈述合成样例与算法输出，不延伸为医疗结论；
- 云证据缺失：直接说明“尚未完成真实验收”，展示适配层和验收清单。
