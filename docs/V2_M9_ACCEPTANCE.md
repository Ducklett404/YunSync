# V2 M9 隐私数据生命周期验收清单

## 1. 已完成的工程交付

- `GET /api/v1/account/export` 导出本人当前保存数据，响应禁止共享缓存，不包含会话令牌、对象存储键或部署秘密。
- 授权撤回后仍允许导出、查询删除状态、取消删除和删除本人报告。
- `DELETE /api/v1/reports/{report_id}` 要求重复报告 ID，先删除私有源文件，再删除数据库记录及其级联数据。
- 账号删除请求具有可配置的 72 小时撤销期；重复请求返回同一待处理记录。
- 请求删除时立即撤回授权，并暂停活动照护方案和旧实验。
- 到期任务清理源文件、账号及关联健康数据，只保留无健康正文的完成墓碑；失败保持待处理并记录通用错误码。
- 过期会话清理和账号删除任务默认 dry-run，`--apply` 还需固定确认短语。

## 2. 自动验收

| 编号 | 验收项 | 期望 |
|---|---|---|
| M9-01 | 本人数据导出 | 200、`private, no-store`、无令牌与存储键 |
| M9-02 | 撤回后导出 | 仍可访问数据权利接口 |
| M9-03 | 角色越权 | 审核角色不能读取参与者导出 |
| M9-04 | 删除请求幂等 | 重复请求返回同一 ID |
| M9-05 | 删除撤销 | 执行时间前可取消 |
| M9-06 | 报告删除确认 | 编号不一致拒绝，成功后记录不可读取 |
| M9-07 | 私有对象清理 | 本地和 OBS 删除幂等，路径穿越被拒绝 |
| M9-08 | 到期账号删除 | 用户健康数据消失，最小墓碑保留 |

## 3. 外部门禁

- 数据控制方批准各数据类别的正式保存期限、删除 SLA 和审计留存期限。
- 目标环境配置受控调度器、最小权限运行身份和失败告警。
- 在 Staging/Production 用合规测试账号完成首次到期删除，并保存数据库、OBS 和审计侧的证据引用。
- 隐私或法务负责人签署更新后的隐私告知文本。

外部门禁未完成前，只能认定 M9 工程实现完成，不能宣称生产隐私流程已正式验收。
