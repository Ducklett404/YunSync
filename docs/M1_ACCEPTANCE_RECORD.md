- M1-01 至 M1-11 全部通过；
- 无天气时不得显示伪造的实时天气；
- 演示数据必须始终有明显标记；
- M1 计划书验收以开发者工具人工验证为准；至少一台真机无阻断性问题作为 M5/M6 发布前硬门槛；
