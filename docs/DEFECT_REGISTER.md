# YunSync 缺陷清单

> 当前基线：M11A / RC1
>
> 更新日期：2026-09-12

## 1. 分级规则

| 级别 | 定义 | RC1 门禁 |
|---|---|---|
| P0 | 数据泄露、越权、健康安全边界失效或主流程完全不可用 | 必须为 0 |
| P1 | 主流程关键步骤失败且无可接受绕行方案 | 必须为 0 |
| P2 | 局部功能、可理解性或兼容性问题，有明确绕行方案 | 记录并排期 |
| P3 | 不影响任务完成的轻微体验或文案问题 | 记录并评估 |

## 2. 当前缺陷

| 编号 | 级别 | 来源 | 问题 | 处理 | 状态 |
|---|---|---|---|---|---|
| M11A-001 | P1 | 弱网代码走查 | 断网或请求超时时直接暴露 Axios 英文错误，用户无法判断下一步 | 统一映射为“检查网络后重试”的中文提示，并保留服务端业务错误原文 | 已关闭 |
| M11A-002 | P2 | 自动化测试 | 当前 FastAPI/Starlette 测试客户端产生上游弃用警告 | 保持 RC1 依赖不做高风险升级；在下一次框架依赖升级时迁移并消除警告 | 待排期 |

当前自动化与本机检查未发现未关闭的 P0/P1 缺陷。该结论只覆盖合成账号、本机 Edge 和离线测试；真实测试者仍可能发现新问题，发现后必须追加登记并重新执行 RC1 门禁。

## 3. 外部验收待办（非缺陷关闭记录）

- 邀请 5 至 10 名真实测试者使用合成账号完成任务；
- 记录完成率、实际耗时、困惑点和安全反馈；
- 在 Chrome、Firefox、Safari 或真实移动设备补充兼容性检查；
- 在受控弱网、断网和恢复场景中完成人工交互复核。
