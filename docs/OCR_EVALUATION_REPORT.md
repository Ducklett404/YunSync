# 合成 OCR 契约评测记录

> 日期：2026-09-11  
> 范围：M4A 合成契约模拟，不是华为云 OCR 准确率评测

## 1. 目的与边界

本记录验证 OCR 适配层能稳定表达指标代码、名称、数值、单位、参考范围、原文、置信度、页码与归一化位置，并验证失败时不产生候选指标。输入只是带场景标记的合成 PDF 字节，不包含真实报告、个人健康信息或真实扫描图像。

因此，下表只能证明接口契约、校对状态和失败降级可以自动化验证，不能用于宣称真实 OCR 的识别率、召回率、字符准确率或医学可用性。

## 2. 合成场景

| 场景 | 指标数 | 置信度范围 | 低于 80% 字段 | 预期行为 |
|---|---:|---:|---:|---|
| standard | 5 | 0.86–0.98 | 0 | 返回完整候选字段与位置 |
| blurred | 5 | 0.52–0.64 | 5 | 全部突出提示并逐项确认 |
| rotated | 5 | 0.74–0.86 | 3 | 返回偏移后归一化位置，低置信字段突出 |
| low_resolution | 5 | 0.43–0.55 | 5 | 保留候选值但全部要求人工核对 |
| timeout | 0 | 不适用 | 不适用 | 标记可重试错误，最多尝试 2 次，不写指标 |
| failure | 0 | 不适用 | 不适用 | 标记不可读错误，只尝试 1 次，不写指标 |

自动化测试覆盖以上六种输入。四种成功场景均要求页码从 1 开始、坐标恰好四项且每项位于 0–1；失败场景断言稳定错误码和是否可重试。

## 2.1 V2 结构化载荷回归补充

V2 另有 `v2-synthetic-report-regression-1` 回归集，包含 20 份无个人信息的结构化 OCR 载荷，覆盖全部 19 个 P0 标准指标以及别名、单位和拒绝路径。其样本矩阵与边界见 `V2_REPORT_REGRESSION.md`，自动化入口为 `tests/test_v2_report_regression.py`。

该回归集从 OCR 已返回结构化字段之后开始验证，因此仍不包含图像识别、版面定位或字符准确率证据。

## 3. 下一阶段真实评测

真实 OCR 接入前需由项目负责人批准脱敏样例和数据处理边界，再至少记录：

1. 标准、模糊、旋转、低清晰度文件各自样本数；
2. 字段级准确率、缺失率、错误单位率、原文定位覆盖率；
3. 服务端耗时分位数、超时率、重试成功率与成本；
4. 低置信阈值的校准依据和人工修正率；
5. OBS 私有访问、删除和生命周期策略的真实证据。

上述真实指标目前均未采集，也没有用合成结果替代。

## 4. 华为云智能文档解析适配状态（2026-09-21）

已实现真实适配器的请求和保守解析路径：

- 使用项目 ID、AK/SK 和显式 OCR 端点构建客户端，配置缺失时关闭失败；
- PNG/JPEG 单次识别；PDF 按页调用并限制 1–20 页，默认 10 页；
- 只接收能映射 P0 指标且同时具有明确数值和单位的表格行；
- 保留页码、置信度和位置，不根据 OCR 数值产生临床阈值或危急判断；
- 多页聚合、未知行忽略和缺配置失败已有契约测试。

当前环境安装华为云 Python SDK 时遭遇外部包源 TLS/文件访问错误，因此仓库已声明 SDK 依赖并使用延迟导入，但本机尚未完成真实凭证调用。没有服务凭证、已开通端点和批准的脱敏文件时，不能形成真实准确率、耗时或服务可用性证据，也不能把 M2 的真实云验收标记为通过。
