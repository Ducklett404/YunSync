# V2 合成报告结构化回归集

> 数据版本：`v2-synthetic-report-regression-1`
> 样本数量：20 份
> 数据性质：完全合成，不含个人信息

## 验证范围

回归集位于 `tests/fixtures/v2_synthetic_report_regression.json`，用于验证 OCR 适配层输出之后的指标标准化与单位投影。20 份记录覆盖：

- P0 指标字典的全部 19 个标准代码；
- 常见中文名、英文缩写和代码别名；
- SI 单位、血糖/血脂 `mg/dL` 换算、单位写法归一；
- 未知非 P0 指标的原身份保留；
- 低置信字段、缺失参考范围、不支持单位；
- 指标代码与名称冲突、无效原文坐标的拒绝路径。

自动化测试要求样本数和 ID 唯一性固定，检查标准代码、名称、原始数值、参考范围、原文、单位投影状态，并保证全部 19 个 P0 代码都有覆盖。冲突样本必须失败，不能静默映射。

## 边界

这些样本是结构化 OCR 载荷，不是 PDF、PNG 或 JPEG 扫描件。`layout` 仅登记计划覆盖的版式类别，不代表系统已识别对应视觉版式。因此，这套回归集可以作为标准化服务的稳定性证据，不能用于计算真实 OCR 的字段完整率、字符准确率、版面定位准确率或云服务可用性。

M2 完整验收仍需经过批准的实际文件级合成或脱敏样本，以及真实 OCR 适配器评测；评测要求沿用 `OCR_EVALUATION_REPORT.md` 的指标和数据边界。
