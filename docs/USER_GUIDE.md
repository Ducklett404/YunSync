# YunSync 用户操作手册

> 当前版本只用于合成数据演示，不应输入或上传可识别个人身份的信息。

## 1. 开始前

云循用于健康教育、生活方式记录和个人短期观察；页面内容与实验结果不构成诊断或治疗建议，也不提供处方或药物调整意见。若存在胸痛、明显呼吸困难、晕厥、持续眩晕，或医生已要求限制相关活动，请停止自助流程并寻求专业帮助。

本地演示地址为 `http://localhost:5173`；生产部署地址需由项目负责人提供。

## 2. 完成演示主流程

### 第一步：登录、授权与安全初筛

1. 打开“开始与安全说明”。
2. 点击“登录演示账号”。
3. 阅读并勾选三项知情说明。
4. 对四个安全问题选择“是”或“否”。
5. 未触发风险时继续；任一项为“是”时，系统会停止自助实验流程。

### 第二步：确认报告

1. 使用内置合成报告，或只选择经批准的合成/脱敏文件。
2. 对 OCR 提取的名称、数值、单位和参考范围逐项核对。
3. 有错误时先修正，再确认该字段。
4. 全部字段确认后再完成报告确认。

不要把 OCR 结果当作医学判断；即使置信度较高，也必须人工核对。

### 第三步：选择一个行动

系统展示三个受治理候选行动及排序分解。阅读适用条件、停止条件、证据摘要和解释来源，一次只选择一个行动。当前排序是产品规则与合成数据演示，不是个体化处方。

### 第四步：执行 14 天实验并每日记录

系统生成固定的提醒日与常规日。只能记录今天或已过去且位于周期内的日期，不能自行更改随机分组。

根据行动填写对应指标，并记录完成情况、缺失原因、睡眠、主观感受、突发事件或不适。明显不适会触发暂停提示；不要为了补齐数据而编造记录。

### 第五步：查看结果并选择下一步

结果页展示有效天数、完成率、两组描述统计、差值、不确定区间和局限。选择“保持、调整、延长或停止”之一，作为下一轮计划记录。短期差异不等于因果证明、诊断或疗效。

## 3. 账号与数据控制

- 在“账号与档案”查看演示档案和当前授权；
- 可以随时撤回授权，撤回后新分析被阻断、活动实验被暂停；
- 可以退出演示账号，原会话立即失效；
- 当前演示数据库仅保存合成数据，正式环境的数据保留与删除规则需在部署前确认。

## 4. 常见问题与恢复

| 情况 | 应对方式 |
|---|---|
| 页面提示无法连接服务 | 检查网络或本地服务，保持页面内容不变后重试 |
| 请求超时 | 等待网络恢复后再次提交；记录接口具备幂等保护 |
| 登录失效 | 返回开始页重新登录演示账号 |
| OCR 失败 | 查看明确错误状态，确认文件要求后使用“重试” |
| 报告无法确认 | 检查是否仍有未逐项确认的字段 |
| 无法创建实验 | 检查授权、安全初筛和是否存在状态冲突 |
| 日程日期无法填写 | 未来、周期外或终态实验均不可记录 |
| 明显不适 | 停止行动，保留实际记录并优先寻求专业帮助 |

## 5. 移动端与可访问使用

移动端底部提供主导航，表单按钮保持适合触控的高度。可以使用键盘完成主要表单和按钮操作；错误与成功信息使用可读文本而非只依赖颜色。若放大文本后出现遮挡，请记录设备、浏览器、缩放比例和页面并提交到缺陷清单。

## 6. 演示边界

当前本地版本不代表真实云部署、真实 AI/OCR 准确率、真实用户研究或健康专业审核。正式试用前必须完成对应外部验收，详见 [EVIDENCE_INDEX.md](EVIDENCE_INDEX.md)。
