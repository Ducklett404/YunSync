# YunSync V2 五分钟演示与降级运行手册

> 主演示使用 `demo/v2_m8_demo_case.json` 中的合成账号和两份合成报告。合成变化只用于展示软件流程，不证明健康效果。

## 1. 演示前门禁

1. 运行 `python scripts/v2_demo_case_check.py`，确认两份报告、至少三项可比指标和算术差通过；
2. 在专用本地演示库执行 `python scripts/load_v2_demo_case.py`；脚本拒绝 Production，重复执行不会复制报告；
3. 确认页面、截图、视频和日志不含真实姓名、联系方式、证件、病历或云密钥；
4. 正式方案只能读取真实专业审核发布的内容；若门禁未通过，展示阻断状态和测试夹具证据；
5. 运行全量验证、敏感信息扫描、材料检查和发布预检；
6. 准备真实云、Mock 和离线三条同版本路径，并记录三轮切换时间。

## 2. 五分钟讲稿

叙事固定覆盖问题、方案、创新、技术、效果、安全。效果只指工程任务完成率、可追溯性和合成数据的算术展示。

| 时间 | 页面/材料 | 讲述与操作 | 证据 |
|---:|---|---|---|
| 0:00–0:35 | 首页 | 问题：报告难读、通用建议难执行；云循提供报告到复查修订的闭环 | 合成数据、非诊疗声明 |
| 0:35–1:15 | 报告 | 录入或 OCR 后核对原值、单位、范围、机构和方法 | 两份报告、定位与确认状态 |
| 1:15–1:55 | 安全档案 | 回答急性症状、危急标记、过敏、孕哺、慢病、用药和肝肾风险 | A/B/C 分流和规则版本 |
| 1:55–2:45 | 食养方案 | 用已发布食材/食谱匹配 1–3 项指标，展示频次、替代和采购清单 | 来源、审核状态、方案快照 |
| 2:45–3:30 | 反馈与复查 | 记录完成/跳过/替换和不适；指定第二份报告并保守对齐 | 暂停、差值门禁、变更日志 |
| 3:30–4:20 | 技术 | 镜像、RDS/DCS/OBS/OCR/MaaS、HTTPS、迁移、监控和告警 | 请求 ID、聚合指标、发布预检 |
| 4:20–5:00 | 安全与结论 | 创新是专业内容门禁和版本追溯；说明真实证据状态 | M8 验收表、发布包 SHA-256 |

## 3. 三套演示路径

### A. 真实云端版

仅在真实 RDS/DCS/OBS/OCR/MaaS、镜像摘要、HTTPS、备份恢复、指标采集、告警送达和专业内容发布证据齐全时使用。只有 `release_preflight.py` 输出 `ready=true` 才称为正式发布演示。

### B. Mock 降级版

本地使用 SQLite、私有目录、合成数据和明确标注的 Mock OCR/MaaS。未发布专业内容时，应如实展示方案被阻断，并用专项测试说明后续状态机。

```powershell
Copy-Item .env.local.example .env
.\start.ps1
```

### C. 截图/离线版

素材顺序为：授权与声明、第一份报告、安全档案、内容审核状态、方案或阻断、反馈与不适暂停、第二份报告、修订版本、部署与预检。每张图标注“合成数据演示”。正式视频和截图包仍需真人录制与客户确认。

## 4. 30 秒切换协议

| 时间 | 操作 |
|---:|---|
| 0–5 秒 | 说明当前路径不可用及将切换到同版本合成数据备份路径 |
| 5–15 秒 | 切换到预先打开的 Mock 标签；本地不可用则打开离线视频 |
| 15–25 秒 | 从当前 V2 步骤继续，不重新开始，不隐瞒降级范围 |
| 25–30 秒 | 再次说明数据来源和未完成的真实验收，回到主时间线 |

三轮演练分别记录真实云到 Mock、Mock 到离线的耗时、卡点和改进。未完成真人计时前，不将降级演练标为通过。

## 5. 中断口径

- OCR/MaaS 超时：显示明确失败，不把 Mock 输出说成真实调用；
- 专业内容未发布：展示安全阻断，不临时发布演示草稿；
- 报告不可比：指出机构、方法、单位或参考范围差异并停止计算；
- 出现不适：暂停活动方案并提示寻求合格专业帮助；
- 云或页面故障：保留当前叙事位置，按 30 秒协议切换；
- 被问及效果：只解释合成算术变化和软件证据，不作医学归因。
