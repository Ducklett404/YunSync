# YunSync V3 · M4 实现记录

日期：2026-09-29  
范围：`V3_MINI_PROGRAM_REDESIGN_PLAN.md` 的 M4（现有食材生成菜谱）  
数据状态：`DEMO_MODE`；真实食谱与替代关系仍待专业签署

## 已实现

- 食材支持搜索输入和分组常用标签，最多录入 15 种，并对番茄/西红柿、豆腐类型、蒜、梨等常见名称做受控同义匹配。
- 常用标签覆盖主食、蔬菜水果、肉蛋奶、豆制品和调味品。
- 可选择制作时间、已有厨具、1/2/4 人份，以及不购买或最多再购买 1/2 种非关键材料。
- 食谱食材新增显式 `isKey` 标记；关键食材缺失时不展示，只有非关键材料缺失数在用户允许范围内才展示。
- 匹配顺序严格为：个人安全门禁 → 内容状态过滤 → 过敏/明确禁忌硬过滤 → 时间与厨具 → 关键材料 → 完全匹配/登记替代/缺料排序。
- 完全具备原材料的食谱优先，其次是使用模板内登记替代的食谱，最后是缺少不超过两种非关键材料的候选。
- 匹配结果明确显示已有材料、需再购买材料和使用的登记替代，不临时生成新配方。
- 无结果时区分个人安全门禁、过敏/禁忌冲突、关键材料不足、厨具或时间不满足，并给出可理解说明。
- 食谱详情支持按 1/2/4 人份等比例换算带数值的食材用量，同时提示烹饪时间和锅具容量仍需人工判断。
- 生产模式只接受 `approved` 内容；当前 `demo` 食谱仅在 DEMO 模式可参与匹配，生产模式自动全部排除。
- 食材匹配和档案保存主按钮支持 H5 点击、键盘聚焦与回车触发，便于跨端人工验收并改善键盘可访问性。

## 关键实现文件

- `miniapp/src/services/pantry.ts`：安全优先的食材匹配引擎。
- `miniapp/src/pages/pantry/index.vue`：食材、厨具、时间、份数和补购条件页面。
- `miniapp/src/pages/recipe/detail.vue`：按目标份数换算用量。
- `miniapp/src/data/m2-content.json`：41 项食材的关键/非关键元数据。
- `miniapp/scripts/validate-m4.mjs`：直接执行实际 M4 源代码的 10 组验收脚本。

## 内容边界

- 当前 12 道食谱和模板内替代关系均为 DEMO 数据，不等于专业审核通过。
- “登记替代”只表示替代关系存在于当前模板，不表示已获得正式专业签署。
- 正式发布前必须将食谱及替代关系改为 `approved`，补齐来源、授权、审核人与签署版本；生产门禁不允许 DEMO 内容通过。
