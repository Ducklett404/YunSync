# YunSync 云循参赛项目报告

> 状态：M12A 内容基线，待按比赛官方模板排版定稿

> 数据边界：本文中的人物、报告、实验记录和结果均为合成数据

## 1. 项目摘要

云循是一套面向体重与代谢健康管理的个人健康行为优化原型。它不直接生成诊断或治疗建议，而是把“读懂已确认的健康信息—选择一个低风险行动—执行 14 天个人微实验—记录并复盘—决定下一轮”组织成可重复、可解释、可审计的闭环。

当前版本已完成本地工程基线和合成数据演示。华为云 OCR、MaaS、OBS、RDS、DCS、IAM、日志监控以及公网部署仍需要真实资源与凭据验收；健康内容仍需专业指导老师审核。

## 2. 问题与目标用户

常见健康建议往往只回答“通常应该怎样”，很难回答“这个低风险行动对当前这个人是否可执行、是否出现了稳定的短期变化”。用户也可能把一次体检指标、AI 解释或短期波动误认为诊断结论。

首版目标用户是希望改善体重或代谢相关生活方式、能够自主完成低风险记录、且没有触发安全初筛条件的成年人。产品目标不是替代医生，而是帮助用户：

1. 明确区分原始报告、用户确认事实、规则排序和 AI 解释；
2. 一次只改变一个行动，降低多变量同时变化造成的混淆；
3. 用固定日程和最小记录负担获得可复盘的个人观察；
4. 在数据不足、风险触发或服务不可用时主动停止或降级。

## 3. 产品闭环

```text
知情说明与安全初筛
  -> 合成/脱敏报告解析与逐项确认
  -> 三个受治理候选行动与透明排序
  -> 14 天 7:7 平衡随机日程
  -> 每日动态记录、缺失原因与不适停止条件
  -> 描述统计、Bootstrap 区间与受控 AI 解释
  -> 保持 / 调整 / 延长 / 停止
```

关键页面依次为开始与安全说明、报告确认、候选行动、个人实验、结果评估、健康总览和账号与档案。页面刷新后以服务端事实为准，客户端不能改写随机分组、未来日期或对象归属。

## 4. 核心创新

### 4.1 从“生成建议”转向“验证一个行动”

大模型只解释受控事实，不能自由生成运动强度、膳食剂量、诊断或调药建议。候选行动来自版本化模板库，排序依据、适用条件、停止条件和证据摘要可见。

### 4.2 可复现的单人短期实验

系统保存随机种子、算法版本、14 天完整日程、锁定时间和摘要。每次读取或写入前重新校验日程完整性；同一天重复提交只更新原记录，不产生重复数据。

### 4.3 安全边界进入业务状态机

授权撤回、高风险初筛或明显不适会阻止分析、暂停实验或停止自助流程。安全不是页面提示，而是由后端权限、对象归属、状态迁移和审计事件共同执行。

### 4.4 云能力可替换、失败可降级

OCR、MaaS、OBS、Redis 和数据库均通过适配层或配置边界隔离。当前 Mock 明确标注为合成模式；缓存不可用不阻断核心流程，模型输出不安全或超时时切换到固定安全解释。

## 5. 技术实现

- 前端：Vue 3、TypeScript、Vite、Pinia、Vue Router、ECharts；
- 后端：FastAPI、SQLAlchemy 2、Pydantic、Alembic；
- 本地数据：SQLite、私有本地对象目录、明确标记的 OCR/MaaS Mock；
- 云端目标：华为云 RDS、DCS、OBS、OCR、MaaS、IAM、ECS/容器环境；
- 工程保障：分层架构、数据库迁移、请求 ID、最小化日志、限流、安全响应头、路径与上传校验、依赖与敏感信息扫描。

详细架构和模块映射见 [TECHNICAL_GUIDE.md](TECHNICAL_GUIDE.md)，数据与接口分别见 [DATA_DICTIONARY.md](DATA_DICTIONARY.md) 和 [API_CONTRACT.md](API_CONTRACT.md)。

## 6. 验证结果

截至 M12A，本地自动化覆盖账号授权、对象归属、上传边界、OCR 契约、模板治理、实验状态机、每日记录、统计分析、缓存降级、HTTP 安全和发布材料完整性。M11A 的合成主流程连续执行 3 次均成功，Edge 在桌面、平板、移动端和 API 断线场景通过渲染烟测。

这些结果只能证明本地代码与合成流程满足当前契约，不代表：

- 真实参与者任务完成率或健康效果；
- 真实华为云服务、网络、配额和公网性能；
- 健康专业审核、临床有效性或医疗器械资格；
- 比赛官方格式和最终提交资格。

完整证据与边界见 [EVIDENCE_INDEX.md](EVIDENCE_INDEX.md)。

## 7. 隐私与健康安全

- 当前开发和演示只允许合成或已脱敏材料；
- Production 强制关闭演示登录、演示种子、本地存储和 Mock AI；
- 原始会话令牌不入库，健康对象按登录用户校验归属；
- 审计日志不保存文件名、健康正文、答案正文或密钥；
- 输出必须声明短期观察的局限，不构成诊断或治疗建议；
- 健康模板和结果措辞在真实试用前必须完成专业审核。

## 8. 华为云落地路线

本地 SQLite、内存缓存、私有目录和 Mock 适配器依次替换为 RDS PostgreSQL、DCS Redis、OBS、OCR 与 MaaS；ECS 或容器环境承载应用，IAM 与密钥管理负责最小权限，日志平台负责请求、错误和告警证据。迁移采用环境变量切换而非改写核心业务规则。

真实云验收必须执行空库迁移、备份恢复、缓存断连、私有对象访问、模型安全样例、HTTPS、镜像扫描、告警送达和公网性能测试。操作步骤见 [CLOUD_OPERATIONS_RUNBOOK.md](CLOUD_OPERATIONS_RUNBOOK.md) 与 [DEPLOYMENT_SECURITY_RUNBOOK.md](DEPLOYMENT_SECURITY_RUNBOOK.md)。

## 9. 当前结论与下一步

云循已形成一个可运行、可测试、可降级的合成数据闭环，并建立了从需求到代码、测试、报告和提交的可追踪证据。正式参赛前仍需完成真实云联调、健康专业审核、真实封闭测试、官方格式核对、PPT 与视频制作以及至少三轮计时演练。
