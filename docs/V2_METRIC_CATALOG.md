# V2 首版指标字典（技术草案）

当前代码版本：`v2-p0-draft-1`。此表对应开发计划书第 5.2 节的 P0 范围，供 OCR 结果对齐标准代码。年龄段、性别等分类字段属于健康档案，不作为数值指标入库。

| 组别 | 标准代码 | 标准名称 | 展示单位 |
|---|---|---|---|
| 基本信息 | `height`, `weight`, `bmi`, `waist_circumference` | 身高、体重、身体质量指数、腰围 | cm、kg、kg/m²、cm |
| 血压 | `systolic_bp`, `diastolic_bp` | 收缩压、舒张压 | mmHg |
| 血糖 | `fasting_glucose`, `hba1c` | 空腹血糖、糖化血红蛋白 | mmol/L、% |
| 血脂 | `total_cholesterol`, `triglyceride`, `ldl_c`, `hdl_c` | 总胆固醇、甘油三酯、低密度脂蛋白胆固醇、高密度脂蛋白胆固醇 | mmol/L |
| 尿酸 | `uric_acid` | 尿酸 | μmol/L |
| 肝功能 | `alt`, `ast`, `ggt` | 丙氨酸氨基转移酶、天门冬氨酸氨基转移酶、γ-谷氨酰转移酶 | U/L |
| 肾功能 | `creatinine`, `egfr`, `urea` | 肌酐、估算肾小球滤过率、尿素 | μmol/L、mL/min/1.73m²、mmol/L |

实现位置：`backend/app/services/metric_catalog.py`。已知代码或名称别名映射到同一标准代码；二者明确指向不同指标时停止自动入库。未知指标保留原名称和代码供人工核对。原文仍保存在 `raw_text`。

本步骤只处理**名称与代码别名**，以及 `mmol/l` 等大小写差异；展示单位不是强制换算目标。`BUN`（血尿素氮）暂不合并到尿素，因为两者数值不能直接等同。数值、检测方法、精度和参考区间仍按原报告保留，不能仅依据这份草案跨报告比较或生成食养方案。下一步需确认各报告版式、原单位、换算系数、参考范围表达方式和专业审核人，再开展数值归一和趋势计算。
