自动化覆盖：

- 匿名健康请求返回 401，登录但未授权的请求返回 403；
- 只接受当前授权版本，同一用户重复接受不会生成多条活动授权；
- 撤回后新的报告分析被拒绝，活动实验变为 `paused`；
- 原始会话令牌不入库，注销后旧令牌返回 401；
- 高风险初筛阻止候选行动与新实验；
- 参与者不能读取审计事件，审核角色不能读取参与者健康工作区；
- 档案审计只记录变更字段名，报告审计不保存上传文件名；
- 报告与实验对象按当前会话用户校验归属。
