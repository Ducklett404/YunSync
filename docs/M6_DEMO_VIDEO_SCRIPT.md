# M6 演示视频脚本

准备日期：2026-10-04。录制内容必须保留 DEMO 标识，不宣称内容已专业签署。

| 时段 | 画面 | 讲解 |
|---|---|---|
| 0—15 秒 | 今日首页，选择城市 | 每日一条主推荐和最多两条备选，手动城市无需定位 |
| 15—35 秒 | 食谱详情，人数、食材、步骤 | 查看结构化做法及来源版本，日常饮食建议不替代诊疗 |
| 35—50 秒 | 收藏、反馈，再打开“我的” | 本机收藏、最近浏览；反馈仅本机记录 |
| 50—75 秒 | 食材录入与完全/缺料匹配 | 展示已有材料、需再买材料和登记替代 |
| 75—95 秒 | 指定大豆过敏场景，重新匹配 | 冲突食谱排除，更改档案后旧结果清除 |
| 95—110 秒 | 天气不可用与安全阻断 | 降级提示明确，高风险输入停止自动推荐 |
| 110—120 秒 | 记录清除确认与版本说明 | 本机保存范围和当前正式发布待办 |

`npm run validate:h5` 会在隔离浏览器中生成流程录像和截图，存放于忽略提交的 `miniapp/test-results/`，用于工程证据。自动测试录像不等于最终讲解视频；正式演示录屏/配音仍待人工整理。
