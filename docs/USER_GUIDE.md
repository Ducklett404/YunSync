# YunSync 用户操作手册

> 当前版本只用于合成数据演示，不应输入或上传可识别个人身份的信息。

## 1. 开始前

云循用于健康教育、生活方式记录和个人短期观察；页面内容与实验结果不构成诊断或治疗建议，也不提供处方或药物调整意见。若存在胸痛、明显呼吸困难、晕厥、持续眩晕，或医生已要求限制相关活动，请停止自助流程并寻求专业帮助。

本地演示地址为 `http://localhost:5173`；生产部署地址需由项目负责人提供。

## 2. 完成演示主流程

### 第一步：登录、授权与安全初筛

1. 打开“开始与安全说明”。
2. 点击“登录演示账号”。
3. 阅读并勾选三项知情说明。
4. 对四个安全问题选择“是”或“否”。
5. 未触发风险时继续；任一项为“是”时，系统会停止自助实验流程。

### 第二步：确认报告

1. 使用内置合成报告，或只选择经批准的合成/脱敏文件。
2. 页面通过登录接口读取源文件；点击指标旁的“定位原文”，在内嵌 PDF 中跳到相应页，或在图片上查看 OCR 定位框。
3. 对 OCR 提取的名称、数值、单位和参考范围逐项核对；页码和定位框只是辅助，仍以原报告可见内容为准。
4. 有错误时先修正，再确认该字段。
5. 全部字段确认后再完成报告确认。

不要把 OCR 结果当作医学判断；即使置信度较高，也必须人工核对。

### 第三步：完善安全档案并查看分流

1. 在“账号与档案”逐项回答过敏、用药、疾病、肝肾、医生限制和特殊状态。
2. 在“安全提示”查看 A/B/C 分流和仍缺少的资料。
3. 资料不全、存在风险或没有真实专业审核发布的规则时，系统会阻止正式方案；不要绕过提示。

### 第四步：生成并确认 7 天食养方案

1. 在“食养方案”选择最多 3 项已确认指标、份数和烹饪条件。
2. 系统只匹配当前有效且具名审核的食材、食谱、禁忌和来源；合格模板不足时明确阻断。
3. 核对目标、食谱卡、材料克数、步骤、频次、替代、7 天安排和采购清单。
4. 用户主动确认后方案才从 `READY` 进入 `ACTIVE`。

当前仓库的合成食谱仍是候审草稿，因此正式参与者路径会安全阻断。工程测试中的“已审核”夹具不代表真实专业批准。

### 第五步：记录执行并设置复查提醒

1. 在“执行与复查”选择已到日期，记录已完成、已跳过或自行替换，并可填写最小必要备注。
2. 自行替换只是事实记录，不会自动成为审核推荐。
3. 出现不适时勾选“不适”；系统立即暂停方案。请停止执行并寻求专业评估，不得自行撤销不适或要求系统自动修订。
4. 按医生建议、报告备注或自己的既定体检计划填写复查日期及依据。系统只在页面内提示到期，不决定医学复查周期。

### 第六步：上传第二份报告并核对新方案

1. 回到“报告确认”上传或手工录入第二份报告，继续逐项核对并完成整份确认。
2. 在“执行与复查”明确选择第一次和第二次报告，查看原值、单位、检查间隔和可比性限制。
3. 方法、参考范围或必要元数据不一致时，系统停止计算差值。显示的算术变化不表示改善、恶化或食谱疗效。
4. 旧方案因新报告暂停后，可选择第二份报告中的已确认指标生成新草案。
5. 核对变更日志后到“食养方案”确认新版；旧版转为只读历史快照。

## 3. 账号与数据控制

- 在“账号与档案”查看演示档案和当前授权；
- 可以随时撤回授权，撤回后新分析被阻断、活动实验被暂停；
- 可以退出演示账号，原会话立即失效；
- 当前演示数据库仅保存合成数据，正式环境的数据保留与删除规则需在部署前确认。

### 3.1 审核员管理 M4 内容

1. 在开始页选择“登录审核员账号”，进入“内容知识库”。
2. 按类型、状态或代码搜索食材、食谱和禁忌规则；勾选条目后可做批量发布依赖校验。
3. 比较版本时选择同一类型、同一代码的两个不同版本，再点击“比较两版”。
4. 审核前填写可核验的资质说明、审核范围和证据记录号；演示身份只能验证流程，不能代替真实专业签署。
5. 批准后条目进入“已审核”，仍须通过来源和依赖校验才能发布。新版本发布会停用旧版本；历史版本只有重新通过当前校验才能回滚。
6. 参与者目录只读取已发布且当前生效的版本。草稿、已审核未发布和停用版本不会提供给后续推荐或 AI 表达层。

## 4. 常见问题与恢复

| 情况 | 应对方式 |
|---|---|
| 页面提示无法连接服务 | 检查网络或本地服务，保持页面内容不变后重试 |
| 请求超时 | 等待网络恢复后再次提交；记录接口具备幂等保护 |
| 登录失效 | 返回开始页重新登录演示账号 |
| OCR 失败 | 查看明确错误状态，确认文件要求后使用“重试” |
| 报告无法确认 | 检查是否仍有未逐项确认的字段 |
| 无法生成方案 | 检查报告、安全档案、专业发布内容以及是否已有待确认或活动方案 |
| 不能填写执行日期 | 只有活动方案中已到的 7 天安排可记录；未来日期不能提前填写 |
| 新报告后不能直接生成普通方案 | 到“执行与复查”使用方案修订流程，保留旧版快照 |
| 明显不适 | 停止方案，保留实际记录并优先寻求专业帮助；系统禁止自动修订 |

## 5. 移动端与可访问使用

移动端底部提供主导航，表单按钮保持适合触控的高度。可以使用键盘完成主要表单和按钮操作；错误与成功信息使用可读文本而非只依赖颜色。若放大文本后出现遮挡，请记录设备、浏览器、缩放比例和页面并提交到缺陷清单。

## 6. 演示边界

当前本地版本不代表真实云部署、真实 AI/OCR 准确率、真实用户研究或健康专业审核。正式试用前必须完成对应外部验收，详见 [EVIDENCE_INDEX.md](EVIDENCE_INDEX.md)。
