## 2. 发布与版本规则

- 生命周期为 `draft` → `prototype_approved` → `retired`；真实专业流程可写入保留状态 `professionally_approved`。
- 同一稳定代码允许保留多个历史版本，但数据库保证最多只有一个活动版本。
- 演示环境只发布活动、低风险、已完成原型规则校验且通过数据与禁忌条件门禁的模板。
- 生产环境只接受 `professionally_approved`；演示审核接口不能写入该状态，避免把内部校验冒充专业结论。
- 已停用的 `retired` 版本不可恢复，需要从合适来源创建新版本并重新审核。

## 3. 透明排序规则

当前规则版本为 `rank-v1`：

```text
适配分 = 证据分 × 0.40 + 可观测性分 × 0.35 + 易执行分 × 0.25
易执行分 = 1 - 执行负担分
```

接口同时返回三个加权分项、权重、模板与规则版本。适配分只用于当前候选项的相对排序，不是疗效概率，也不替代安全门禁。

## 4. 解释守卫

解释策略版本为 `action-explain-v1`。模型仅接收已发布模板和排序分项，不接收报告原文、身份信息、诊断详情、药物名称或自由文本健康备注。服务端再次校验长度、行动名称以及诊断、调药、极端干预和疗效承诺等禁用模式；超时、服务错误或输出不合规时改用固定说明，并把来源标记为 `policy_fallback`。
