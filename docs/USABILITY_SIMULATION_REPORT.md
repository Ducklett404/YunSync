# YunSync 第 1 周可用性仿真走查报告

> 执行日期：2026-09-10  
> 报告类型：合成用户画像 + 浏览器自动化仿真  
> 数据范围：项目内置合成报告、合成指标与合成实验记录  
> 结论限制：本报告不是 3 至 5 名真实同学的可用性测试，不能作为真实用户研究证据

## 1. 仿真目的

在不采集真实健康数据的前提下，验证第 1 周原型的主流程是否机械可完成、安全拦截是否有效、三类行动是否进入正确记录与结果页面，以及桌面和移动端是否出现页面级横向溢出。

仿真执行了 [USABILITY_TEST_PLAN.md](USABILITY_TEST_PLAN.md) 中 T-01 至 T-05 的流程。每个合成用户都重新从 `/start` 开始，并完成报告确认、行动选择、创建计划、保存一条合成记录和查看结果。

## 3. 核验结果

- 5/5 流程显示“不提供疾病诊断、治疗、处方或药物调整意见”。
- 5/5 报告页显示合成数据标记和已确认状态。
- 三类行动均能创建 14 天计划并显示对应主要指标。
- 5/5 能保存一条合成记录，并进入结果评估页面。
- 5/5 结果页同时显示有效观测和“不能描述”的结论边界。
- 1440、1280、1024、390、320 px 五个视口均未检测到页面级横向溢出。
- P05 验证安全停止提示可见，修复后不能从侧栏绕过安全门。

## 4. 发现与修复

### SIM-01 安全初筛可被导航绕过

- 严重度：P0（安全边界）
- 发现：安全问题回答“是”后，页面虽然禁用了继续按钮，但用户仍可点击侧栏“报告确认”直接离开 `/start`。
- 修复：新增仅在当前页面会话内有效的前端访问状态，并为其余五个主流程路由增加前置守卫；未完成初筛或触发拦截时统一返回 `/start`。
- 回归：P05 先触发安全项，再尝试进入报告页，最终 URL 保持 `/start`；纠正为全部“否”并完成知情确认后才能继续。
- 限制：前端守卫只是交互原型。正式版本仍必须在后端 API 校验有效授权和安全状态。

## 5. 仿真结论

里程碑 M1B“合成用户仿真走查与安全守卫修复”通过。当前原型在所测视口和合成路径中可以完成 T-01 至 T-05，且已修复本轮发现的 P0 问题。

第 1 周原计划中的“3 至 5 名真实同学走查”仍保持待执行。只有真实参与者完成测试后，才能正式确认“无需口头指导”和“每日记录中位耗时不超过 60 秒”。
