# V2 初步安全分流规则（待专业审核）

规则版本：`v2-safety-preliminary-2`。实现：`backend/app/services/safety_decision_service.py`。此版本仅使用用户主动回答的初筛、食养安全档案和最新报告的用户确认状态，不使用血压、血糖等数值阈值，也不作疾病判断。

| 优先级 | 输入条件 | 返回状态 | 方案权限 |
|---|---|---|---|
| 1 | 初筛明确报告急性症状 | C 层 `urgent_care` | 禁止生成，提示及时联系当地急救服务 |
| 2 | 用户确认最新报告由出具机构明确标注危急值 | C 层 `urgent_care` | 禁止生成，提示尽快联系出具机构或医生核实 |
| 3 | 其他初筛风险、过敏/用药/疾病/医生限制、孕哺或其他特殊状态 | B 层 `consult_professional` | 禁止生成，先咨询专业人员 |
| 4 | 初筛、档案、最新报告逐项确认或报告危急标记核对未完成 | `complete_information`，暂不分层 | 禁止生成，列出待补项目 |
| 5 | 资料完整且没有上述已知风险 | `awaiting_review_rules`，暂不归入 A 层 | 禁止生成，等待食材、食谱和规则经专业审核 |

**规则边界**：

- 本版本不依据报告数值判断危急值，也不判定任何疾病、过敏原或药物相互作用。
- 报告危急标记默认为 `unknown`。只有用户对照报告原件明确选择 `yes` 才触发第 2 条；选择 `no` 只表示未见机构明确标注，不代表检验结果正常。支持更正选择，安全接口即时重算。
- 完整填写不代表低风险。A 层须在专业审核规则、内容库和方案安全扫描完成后另行实现。
- 同一人更新初筛或食养安全档案后，接口即时重算，不缓存旧结果。
- 对急性症状的保守提示依据开发计划书第 8.1 节；[国家卫生健康委急救科普材料](https://www.nhc.gov.cn/xcs/c100122/202405/f251e896a50a49ff8c632b4b3da93126/files/1734001844015_12363.pdf)也将胸痛、呼吸困难等列为应联系急救服务的情形。服务地区未冻结，界面不写死急救号码。
- [国家卫生健康委《医疗质量安全核心制度要点》](https://www.nhc.gov.cn/yzygj/c100068/201804/42ab2552298047679cd6ec733f233862.shtml)要求医疗机构建立可追溯的危急值报告流程并及时通知相关医师。本产品只保守记录用户的原件核对结果，不代替机构的报告与临床处置流程。

专业审核待办：明确服务地区、复核初筛问题措辞、复核报告危急标记的用户文案和处置流程、审核 B/C 分层条件，并签署版本记录。审核前不得将本规则作为正式医疗分诊或食养方案准入依据。
