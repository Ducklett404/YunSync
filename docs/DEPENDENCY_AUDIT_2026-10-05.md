## 剩余风险处置

剩余 48 条来自当前 DCloud 5.24 编译链及其固定的 Vite 5.2.8、压缩、图片和文件扫描工具。npm 给出的主要自动修复会把 DCloud Vue 3 包降到旧的 0.x/2.x 版本或使用强制 peer 覆盖。实测把 Vite 单独升到 5.4.21 会使 `npm ci` 因 DCloud 精确要求 `vite@5.2.8` 而失败，因此未提交不可复现的强制组合。

当前措施：

- Vite 开发服务器只监听 `127.0.0.1`；
- 开启严格文件访问并只允许 localhost/127.0.0.1 跨域来源；
- CI 和本地构建不处理来自不可信用户的 ZIP、图片、源码或路径参数；
- 正式产物不部署 Node 开发服务器；
- `npm audit --omit=dev` 必须保持为 0；
- DCloud 发布兼容的新编译链后整体升级并重跑 M2—M6、微信构建和 H5 页面回归。
