# V2 M10 工程验证记录

> 验证日期：2026-09-27

## 1. 验证范围

本轮合并验证两组 M10 工程能力：跨报告显示精度和保守可比性门禁；持续集成、CycloneDX SBOM、发布物供应链信息、Prometheus 告警、只读 Staging HTTPS 验收和性能证据工具。

## 2. 自动验证结果

### 2.1 已完成的工程行为

- `health_metrics.reported_precision` 保存原报告显示的 0–6 位小数，不改写数值；手工录入、指标校对和可可靠识别的 OCR 原文均可记录显示精度。
- 检测机构、检测方法、显示精度或参考范围缺失/变化时不返回算术差；常见单位字符形式差异不会被误判为数值单位变化。
- GitHub Actions 对迁移、后端回归、仓库与依赖安全、材料、告警、SBOM、前端类型和构建设置门禁。
- 容器和发布 ZIP 携带 CycloneDX 1.5 SBOM；直接生产依赖未安装或前端版本未锁定时默认失败。
- 只读 Staging 工具检查 HTTPS、证书、重定向、健康/就绪、匿名访问和安全头；性能工具输出 P50/P95/P99、错误率和吞吐量。
- Prometheus 基线覆盖目标不可用、错误率、P95 延迟和限流突增，并禁止用户、报告、请求和存储对象等高基数标签。

### 2.2 验证结果

- M10 可比性专项覆盖可比、机构变化、精度变化、精度缺失和单位形式等价路径。

- 华为云核心 SDK 的当前版本约束与 `pyasn1 0.6.4` 安全修复冲突；三项云 SDK 不进入默认运行依赖，真实云模式保持关闭失败，不通过忽略漏洞或强制覆盖依赖启用。
