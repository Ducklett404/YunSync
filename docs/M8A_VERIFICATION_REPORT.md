## 1. 已完成范围

- 结果分析改为使用所有非空主要指标值，行动完成率和指标有效率独立计算；
- 三类行动分别计算提醒日/常规日有效天数、均值、中位数和“提醒日 − 常规日”差异；
- 使用固定分析版本与随机种子的 2,000 次 Bootstrap 生成可复现的 95% 重采样区间；
- 提醒日或常规日少于 2 个有效值时，隐藏均值、中位数、差异、区间和方向性结论；
- 按组内 IQR 规则标记异常值，主分析保留原值；剔除后两组仍足够时另列敏感性差异；
- 汇总忘记、设备不可用、身体不适、计划外事件、其他、未说明和尚未记录等缺失原因；
- 新增 `result-explain-v1` 提示词、输出长度/指标/安全边界校验，以及诊断、调药和疗效保证守卫；
- Mock 或真实 MaaS 不可用、超时、报错或越界时，明确回退到 `policy_fallback` 固定解释；
- 结果页展示数据质量、解释来源与策略版本，并提供保持、调整、延长、停止四种可改选方案；
- 下一步选择单独持久化并写入只含实验 ID 与代码的最小审计事件，不自动改变实验状态。

## 3. 验证边界

- 本报告没有使用真实健康数据、真实参与者或真实设备数据。
- `mock_maas` 只是受控适配器契约验证，不是华为云 MaaS 成功调用证据；真实接入仍属于第 9 周外部云联调。
- 行动模板与结果措辞尚未获得健康专业指导老师审核，不以合成金标准替代专业审核。
- Bootstrap 区间、IQR 标记和方向标签只服务于个人短期探索性复盘，不证明因果、疾病疗效或长期效果。
- 浏览器自动化组件此前因运行环境内核资源错误无法可靠截图和点击；本轮不会伪造交互式浏览器验收，真实视觉与键盘走查仍需后续完成。
