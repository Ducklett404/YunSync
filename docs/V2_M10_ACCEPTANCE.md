# V2 M10 持续交付与 Staging 验收清单

## 1. 已完成的工程交付

- `.github/workflows/ci.yml` 在提交和拉取请求上执行数据库迁移检查、后端全量测试、仓库安全扫描、Python/npm 生产依赖审计、材料检查、告警规则校验、SBOM 生成、前端类型检查和生产构建。
- `scripts/generate_sbom.py` 从当前 Python 生产环境和前端锁文件生成 CycloneDX 1.5 SBOM；直接依赖缺失或未锁定时默认失败。
- `Dockerfile` 和 `scripts/build_release_package.py` 将 `SBOM.cdx.json` 纳入运行镜像和发布压缩包。
- `deploy/prometheus-alerts.yml` 提供实例不可用、错误率、P95 延迟和限流突增基线；标签中禁止用户、报告、请求或存储对象标识。
- `scripts/staging_acceptance.py` 只读检查 HTTPS、证书剩余时间、HTTP 重定向、健康/就绪、未授权访问、请求 ID 和安全响应头，证据文件不保存域名、令牌或响应正文。
- `scripts/performance_smoke.py` 输出 P50/P95/P99、最大值、错误率和吞吐量；公网目标强制 HTTPS，20 个独立短期令牌必须来自仓库外文件。

## 2. 自动验收

| 编号 | 验收项 | 期望 |
|---|---|---|
| M10-01 | CI 最小权限与双栈门禁 | `contents: read`；后端与前端门禁齐全 |
| M10-02 | SBOM | CycloneDX 1.5；Python 直接依赖已安装；前端生产依赖使用锁定版本 |
| M10-03 | 发布物 | 容器和 ZIP 均包含 `SBOM.cdx.json` |
| M10-04 | 告警规则 | 四项规则齐全，包含级别和持续时间，无高基数隐私标签 |
| M10-05 | Staging 地址 | 公网只接受无凭据、查询和子路径的 HTTPS origin |
| M10-06 | HTTPS 与证书 | HTTP 重定向到同一 HTTPS origin；证书校验通过且剩余至少 14 天 |
| M10-07 | 应用边界 | `/healthz`、`/readyz` 正常；账号状态匿名访问返回 401；安全头齐全 |
| M10-08 | 性能证据 | 普通与核心端点记录 P50/P95/P99、错误率、吞吐量并应用阈值 |
| M10-09 | 令牌保护 | 独立短期令牌文件位于仓库外，报告和日志不输出令牌 |

## 3. 外部门禁

- 在目标构建环境生成不可变镜像摘要，并保存镜像漏洞、秘密和软件组成扫描结果。
- 在公网 Staging 运行只读验收，保存经批准的证据文件和执行时间；域名及内部网络信息按组织规则脱敏。
- 在真实 RDS/DCS、多实例和公网链路下使用至少 20 个独立测试账号执行负载测试，保存资源曲线和 P50/P95/P99。
- 将告警规则部署到真实监控平台，见证触发、通知送达、确认、恢复和责任人签字。
- 完成回滚到上一不可变镜像、数据库备份恢复和发布负责人签署。

以上证据依赖目标云资源和真实接收渠道。工程工具通过只表示可以执行验收，不能宣称 M10 已完成生产部署验收。
