# YunSync V3 · M3 实现记录

日期：2026-09-29  
范围：`V3_MINI_PROGRAM_REDESIGN_PLAN.md` 的 M3（个人情况与今日推荐）  
数据状态：`DEMO_MODE`；真实身份、问卷授权和专业内容签署仍延迟绑定

## 已实现

- 将轻量档案扩展为城市、年龄段、适用人群、已知过敏/不耐受、确诊情况、正在用药、医生饮食限制、饮食偏好和体质问卷填写意愿。
- 所有档案和每日体感仅保存在本机；M3 不新增精确定位或云端健康数据写入。
- 体质参考问卷未取得授权，因此严格保持关闭；只记录“愿意稍后填写”，未虚构题目、分型或结果。
- 今日体感支持计划书规定的 7 个固定选项，并允许补充轻微不适文本。
- 高热、呼吸困难、胸痛、意识异常、持续呕吐、明显脱水、症状持续加重命中后停止食谱个性化并提示及时就医。
- 儿童、孕哺期、复杂慢病、肿瘤治疗期、透析期、进食障碍不进入自动个体化推荐。
- 确诊情况或用药信息存在时采用保守门禁；无法由当前演示食谱可靠执行的低盐、低钠、限钾、限磷、限糖、流质、低嘌呤、低蛋白等医生限制也停止推荐。
- 过敏和可解析的明确食材禁忌在排序前硬过滤，冲突食谱不进入主推荐或备选。
- 推荐引擎采用“安全门禁 → 审核食谱召回 → 节日/节气、地域、固定体感、偏好排序 → 近期主推荐降权 → 最多 3 条输出”。
- 首页输出 1 条主推荐和最多 2 条备选；推荐原因默认显示最多 4 项，完整依据折叠展示。
- 最近 7 次主推荐用于降权去重复；天气不可用或内容包候选被过滤时回退到城市季节通用内容，不伪造实时天气。
- 无安全候选时返回明确空状态，不用未知替代项强行补满。

## 关键实现文件

- `miniapp/src/services/safety.ts`：高风险、特殊人群、疾病/用药和医疗限制门禁。
- `miniapp/src/services/recommendation.ts`：硬过滤、可解释排序、去重复和降级。
- `miniapp/src/services/checkin.ts`：按日期保存每日体感。
- `miniapp/src/services/history.ts`：保存近期主推荐。
- `miniapp/src/pages/profile/index.vue`：M3 轻量档案。
- `miniapp/src/pages/today/index.vue`：安全筛查、体感、1 主 2 备选和原因展示。
- `miniapp/scripts/validate-m3.mjs`：直接打包并执行生产源代码的 M3 验收脚本。

## 数据与发布边界

- 当前安全词表是计划书风险边界的工程化 DEMO 规则，不替代医疗分诊系统。
- 当前 12 道食谱仍为演示内容；正式来源、授权、营养/中医药/食品安全审核人与签署版本未完成。
- 正式发布前必须替换真实主体、隐私联系人、天气服务和内容签署配置，并通过生产门禁。
