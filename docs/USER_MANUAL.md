# 云循使用手册（DEMO 版）

更新时间：2026-10-04。当前版本用于功能体验，食谱尚未正式专业签署。

## 今日吃什么

打开“今日”，选择城市和当天体感，查看一条主推荐与最多两条备选。点击“看食材和做法”查看人数、制作时间、厨具、用量与步骤。“完整排序依据”可展开查看原因。

DEMO 版顶部可以切换加载、无天气、错误、空数据和节庆日期样例。天气不可用时会明确提示并使用通用内容。城市可以手动选择，无需定位权限。

## 手头食材能做什么

打开“食材”，输入食材或点选标签，最多 15 种。选择制作时间、已有厨具、1/2/4 人份以及是否接受补购最多两种非关键材料，点击“开始匹配”。

结果区分材料齐全、模板中登记的替代、缺少少量材料。详情用量会随人数换算；烹饪时间和锅具容量还需要按实际情况调整。修改条件后旧结果会清除，需要重新匹配。

## 我的档案、收藏与反馈

在“我的”填写城市、年龄段、适用人群、过敏与医生饮食限制并保存。档案用于安全筛查和排序。更改档案返回食材页后，旧匹配结果会清除。

食谱详情可收藏或取消收藏，最多 50 道。“我的”中查看收藏与最近 20 道浏览记录；内容停用、删除或待审核时会标为不可用，版本变化会显示更新提示。

反馈提供“有帮助、制作太复杂、步骤不清楚、食材不好准备”选项。反馈绑定食谱版本，只保存在本机，不会发送给运营人员。

## 本机记录

档案、体感、收藏、浏览记录和反馈保存在当前设备，不跨设备同步。“清除收藏、浏览与反馈”需要确认，清除后无法恢复，但安全档案和体感会保留。

保存失败时请按页面提示重试；食谱仍可浏览，但失败的记录不会被当作成功保存。

## 服务边界

日常饮食建议不替代诊疗。高风险描述、超出服务范围的人群或需要专业核对的医疗条件会停止自动推荐。体质问卷当前只记录后续填写意愿，尚未启用。
