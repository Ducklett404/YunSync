## 1. 已完成范围

- 行动模板支持稳定代码、版本、审核状态、审核范围、审核引用、活动状态和停用时间；
- 同一代码保留历史版本，数据库约束最多只有一个活动版本；
- 演示审核接口支持查看、克隆新版本、原型规则校验、启用和停用，并写入审计事件；
- Production 仅发布 `professionally_approved`，演示审核接口不能伪造该状态；
- 候选生成前检查安全初筛、最新报告、全部指标确认、最低指标数量、模板状态、低风险、禁忌代码和信号指标；
- `rank-v1` 返回证据、可观测性、易执行三个加权分项与规则版本，并明确分数不是疗效概率；
- `action-explain-v1` 限制输入和输出；诊断、药物调整、极端干预、疗效承诺、超时及服务错误均触发固定安全说明；
- 前端展示模板版本、审核范围、排序分项、解释来源、策略版本和安全检查结果；
- Alembic 迁移 `b5c6d7e8f9a0_action_template_governance` 与产品、架构、接口、数据和环境文档同步。
