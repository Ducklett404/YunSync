三项提供方验收完成后，把脱敏证据编号写入 `HUAWEI_OBS_VALIDATION_REF`、`HUAWEI_OCR_VALIDATION_REF`、`HUAWEI_MAAS_VALIDATION_REF`，执行：

```bash
python scripts/cloud_preflight.py --env-file .env
```

`ready=true` 是配置门禁通过，不代表全部用户和专业验收已完成。

## 5. 关闭标准

- 真实云六项均有可核验脱敏证据，`cloud-preflight-v4` 通过；
- 5—10 名测试者均有独立记录，汇总结论可追溯；
- 全部用户可见健康内容按版本完成专业复核；
- P0/P1 为零，自动化全量回归、前端类型检查和生产构建通过；
- 结果回填 `V2_M7_ACCEPTANCE.md`，由责任人本人签署。
