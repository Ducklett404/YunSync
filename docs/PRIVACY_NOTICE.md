# YunSync V2 隐私说明（交付审阅稿）

> 正式发布前，客户的数据控制方、法务/隐私负责人须结合服务地区、主体名称、联系方式、保留期限和供应商合同完成审阅并登记版本。

## 1. 目的与范围

YunSync 用于帮助用户整理体检报告、建立食养安全档案、查看经审核的食养方案、记录执行反馈，并对两次已确认报告进行保守对齐。系统不作诊断，不替代医生，也不自动推断复查周期、用药或治疗建议。

在明确授权后，系统可能处理账号标识、报告文件和结构化指标、检查日期/机构/方法、风险与过敏档案、方案偏好、执行及不适反馈、方案版本和最小化审计信息。演示环境只使用合成数据。

## 2. 使用、共享与自动化

- 报告文件仅用于受控提取、核对和方案流程；
- AI/OCR 输出须经过服务端结构和安全校验，不能作为医学结论；
- 云数据库、对象存储、缓存、OCR 和模型服务按合同与最小权限使用；
- 不将健康数据用于广告画像或未说明的共享；
- 日志和监控只记录请求 ID、路由模板、状态、耗时和聚合事件。

## 3. 保留、安全与用户权利

正式保留期限由数据控制方在上线前填写并公示。到期数据按批准流程删除或匿名化。系统采用 HTTPS、私有对象存储、角色权限、独立迁移身份、加密备份、秘密管理、版本审计和事故响应。

用户可以撤回授权、查询或更正本人资料、导出账号数据、删除单份报告或请求删除账号，并可选择手工录入而不上传原报告。撤回授权会停止后续方案流程，但仍可使用导出和删除功能。账号删除默认提供 72 小时撤销窗口；到期后删除私有源文件和关联健康数据，仅保留不含健康正文的最小审计墓碑。急性症状、危急值或不适提示应联系合格专业人员或当地急救服务。
