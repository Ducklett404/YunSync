# YunSync V3 · M5 实现记录

日期：2026-10-04

状态：收藏、最近浏览、简单反馈和内容状态影响的首批工程实现已完成；M5 整体验收待完成。

## 本次实现

- 食谱详情支持收藏/取消收藏，最多 50 道；重复收藏不产生重复记录，达到上限时提示先移除收藏。
- 打开有效食谱详情记录最近浏览，按最近一次打开置顶、去重，最多 20 道。
- 食谱反馈提供“有帮助、制作太复杂、步骤不清楚、食材不好准备”四种选项；仅本机保存，每道食谱保留一条最新反馈，最多 50 条，绑定所反馈的食谱版本。
- “我的”新增收藏、最近浏览及清除记录入口；清除前弹窗确认，仅删除上述三类记录，保留安全档案和体感。
- 收藏/浏览保留名称和版本快照。食谱更新时显示版本变化；停用、草稿、已移除内容保留历史名称并关闭查看入口，停用收藏仍可移除。
- 首页推荐、节庆内容包、食材匹配、详情和本机记录采用统一可用性规则：正式模式只允许 `approved` 且 `isDemo=false`；演示模式额外允许 `demo` 且 `isDemo=true`；草稿和停用内容均不放行。
- 本机存储读取失败时列表降级为空状态，禁止后续写入覆盖旧数据；写入/删除失败会报告给页面，避免显示虚假成功。
- 修复详情无效 URL 编码导致的异常，并补充反馈、档案与本机记录的说明。

## 主要文件

- `miniapp/src/services/engagement.ts`：有上限的本机记录与版本快照。
- `miniapp/src/services/content.ts`：审核状态与演示/正式数据可用性判断。
- `miniapp/src/pages/recipe/detail.vue`、`miniapp/src/pages/profile/index.vue`：收藏、反馈、记录列表和清除入口。
- `miniapp/scripts/m5-validation-entry.ts`、`miniapp/scripts/validate-m5.mjs`：直接执行实际源代码，覆盖存储异常、内容生命周期及数量上限。
