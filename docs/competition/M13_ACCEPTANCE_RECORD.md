# M13 受控 AI 工程验收记录

更新时间：2026-10-09

状态：**工程实现与本地模拟验收完成；真实华为云 MaaS 尚未开通，云端调用验收待执行**。

## 交付范围

- 首页“一句话告诉云循”卡片和 `POST /v1/recommendations/natural`。
- 服务端 MaaS V2 Chat 适配，API Key、完整 API 地址和 model 参数仅从环境变量读取。
- 抽取阶段严格校验 JSON Schema、受控枚举、最多 15 种食材、200 字输入和置信度；食材与偏好必须在审核库允许列表内。
- 说明阶段只接受本次推荐实际命中的原因码，服务端拼接受控短句；模型不能返回新的食材、用量、做法或功效。
- 服务端在调用模型之前阻断高风险症状、不支持人群、疾病/用药及特殊饮食限制；从原话提取的过敏/禁忌与档案限制合并硬过滤。
- 超时/短暂错误重试、Redis TTL 缓存、连续失败熔断和确定性规则降级。
- `ai_output_audits` 仅保存请求 ID、提示词版本、阶段、状态、食谱 ID 与版本；不保存原话、密钥或自由生成文本。
- 结果展示天气、地域、节庆节气、体感和现有食材因素，以及食谱来源和版本。

## 本地验收

- 后端测试：31/31 通过；包含正常抽取、模型缓存、异常 JSON、未知字段、虚构食材、超时、熔断、过敏冲突、提示词注入、高风险、超长输入及未识别食材空结果。
- 小程序：TypeScript 类型检查、M2—M6 回归、H5/微信小程序构建通过；H5 页面流程 9/9 通过，其中包含一句话风险拦截、过敏排除和现有食材匹配。
- 所有模拟 MaaS 返回均通过本地 `httpx.MockTransport`；没有声称已访问真实 MaaS。
